# Daily Fresh — Comprehensive App Icon Guide

This document provides a screen-by-screen breakdown of all `MaterialCommunityIcons` used in the Daily Fresh customer application.

---

## 1. Global Navigation (Tab Bar)
| Tab | Icon (Active / Inactive) |
| :--- | :--- |
| **Home** | `home` / `home-outline` |
| **Favorites** | `heart` / `heart-outline` |
| **Categories** | `view-grid` / `view-grid-outline` |
| **Cart** | `cart` / `cart-outline` |

---

## 2. Icons by Screen

### Home Screen
- `magnify`: Search bar
- `map-marker-radius`: Current location indicator
- `chevron-down`: Location selector dropdown
- `store-outline`: Branch/Store indicator
- `cart-outline`: Header cart access
- `timer-outline`: Delivery time badge
- `arrow-right-circle-outline`: "View All" sections

### Search Screen
- `magnify`: Search input
- `arrow-left`: Back navigation
- `close-circle`: Clear search input
- `emoticon-sad-outline`: No results found state

### Categories & Product Listing
- `tune-variant`: Filter/Sort button
- `arrow-left`: Back navigation
- `basket-off-outline`: No products available (Categories)
- `basket-remove-outline`: No products found (Listing)

### Cart & Checkout
- `minus` / `plus`: Quantity controls
- `trash-can-outline`: Remove from cart (MiniCart)
- `map-marker-radius`: Address selection (Cart)
- `chevron-right`: Checkout navigation
- `map-marker`: Shipping address indicator
- `alert-circle-outline`: Payment error/warning

### Order Success & Detail
- `check-bold`: Central success checkmark
- `arrow-right`: "Continue Shopping" button
- `refresh`: Reorder action
- `share-variant`: Share order details
- `help-circle-outline`: Support/Help link
- `map-marker-outline`: Delivery address in details

### Account & Profile
- `pencil-box-outline`: Edit profile link
- `power`: Logout (Red)
- `camera`: Update profile picture
- `account-outline`: Name field icon
- `email-outline`: Email field icon
- `phone-outline`: Phone field icon
- `chevron-right`: Menu item navigation

### Saved Addresses & Add Address
- `plus`: Add new address
- `map-marker-off-outline`: No addresses state
- `dots-vertical`: Address options menu
- `crosshairs-gps`: Use current location (Picker)
- `map-marker-off`: Unserviceable area (Picker)

### Favorites & Referrals
- `heart` / `heart-outline`: Wishlist toggles
- `gift-outline`: Referral page header
- `content-copy`: Copy referral code
- `share-variant`: Invite friends

### Notifications & Support
- `bell-off-outline`: No notifications state
- `chat-processing-outline`: Live chat/Support link
- `arrow-left`: Back navigation

### About Screen
- `leaf`: Sustainability/Brand logo
- `check-circle`: Feature/Quality bullets
- `facebook`: Social link
- `instagram`: Social link
- `twitter`: Social link

## 3. Icons by Component

### ProductCard
- `plus` / `minus`: Add to cart / Update quantity

### MiniOrderStatus
- `close-circle`: Hide status bar
- `chevron-right`: Track order link

### MiniCart
- `trash-can-outline`: Remove item
- `chevron-right`: Expand cart
